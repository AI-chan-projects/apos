🧠 1. Causal 중복 문제 해결 상태

✅ 해결됨 (거의 완전히)

이유는 이거야:

✔ core/causal

→ “순수 causal reasoning layer”

* causal_trace_engine
* causal_graph_builder
* failure_attribution_engine
* root_cause_ranker

👉 역할: “왜 발생했는가”

⸻

✔ ui/causal

→ “표현 + 인터랙션 layer”

* viewer
* router
* bind service
* timeline API

👉 역할: “보여주고 연결하는 layer”

⸻

✔ runtime/scheduler (이동된 causal_dag_scheduler 자리)

→ “causal → execution bridge”

👉 역할: “왜를 기반으로 실행 순서 결정”

* ui/causal (presentation)
* runtime/scheduler (execution binding)

👉 이건 문제 아님
👉 오히려 “3-layer causal architecture”로 정상 설계 상태
